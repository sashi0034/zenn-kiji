---
title: "予約済みキーワードとトークン (Reserved keywords and tokens)"
---

以下はスクリプト言語によって予約されているキーワードです。これらはスクリプト内での識別子（変数名や関数名など）として使用することはできません。また、ホストアプリケーションによっては、これら以外にも独自のキーワードを予約している場合があることに注意してください。

**予約済みキーワード:**

| | | | | |
|---|---|---|---|---|
| `and` | `do` | `in` | `not` | `typedef` |
| `auto` | `double` | `inout` | `null` | `uint` |
| `bool` | `else` | `int` | `or` | `uint8` |
| `break` | `enum` | `interface` | `out` | `uint16` |
| `case` | `false` | `int8` | `private` | `uint32` |
| `cast` | `float` | `int16` | `protected` | `uint64` |
| `catch` | `for` | `int32` | `return` | `using` |
| `class` | `foreach` | `int64` | `switch` | `void` |
| `const` | `funcdef` | `is` | `true` | `while` |
| `continue` | `if` | `mixin` | `try` | `xor` |
| `default` | `import` | `namespace` | | |

**コンテキスト依存キーワード（識別子としても使用可能）:**

以下のキーワードは特定の文脈（コンテキスト）において特別な意味を持ちますが、それ以外の場所では関数名や変数名などの識別子として使用できます。

| | | | | |
|---|---|---|---|---|
| `abstract` | `external` | `function` | `property` | `super` |
| `delete` | `final` | `get` | `set` | `this` |
| `explicit` | `from` | `override` | `shared` | |

**非アルファベットトークン:**

| | | | | |
|---|---|---|---|---|
| `*` | `)` | `**=` | `<<` | `...` |
| `**` | `==` | `++` | `>>` | `&&` |
| `/` | `!=` | `--` | `>>>` | `\|\|` |
| `%` | `?` | `&` | `&=` | `!` |
| `+` | `:` | `,` | `\|=` | `[` |
| `-` | `=` | `{` | `^=` | `]` |
| `<=` | `+=` | `}` | `<<=` | `^^` |
| `<` | `-=` | `;` | `>>=` | `@` |
| `>=` | `*=` | `\|` | `>>>=` | `!is` |
| `>` | `/=` | `^` | `.` | `::` |
| `(` | `%=` | `~` | | |

上記のトークン以外に、数値トークン、文字列トークン、識別子トークン、コメントトークンもあります：

```
123456789
123.123e123
123.123e123f
0x1234FEDC
0d123987
0o1276
0b1010
'abc'
"abc"
"""heredoc"""
_Abc123
//
/*
*/
```

スペース (32)、タブ (9)、キャリッジリターン (13)、ラインフィード (10)、および UTF8 バイトオーダーマーク (U+FEFF) はすべてホワイトスペースとして認識されます。
