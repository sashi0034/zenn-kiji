## 代入 (Assignments)

```cs
lvalue = rvalue;
```

`lvalue`（左辺値）は、式の値を格納できるメモリ上の場所（変数など）を指す式でなければなりません。代入式全体は、格納されたデータと同じ値と型として評価されます。右辺の式は常に左辺の前に計算されます。

## 関数呼び出し (Function call)

```cs
func();
func(arg);
func(arg1, arg2);
lvalue = func();
```

関数は特定の処理（アクション）を実行するために呼び出され、その結果として値を返す場合があります。関数が複数の引数を取る場合、引数の式は逆順（最後の引数が最初）に評価されます。

一部の関数は、複数の値を返すために「出力参照パラメータ（`out` 参照）」を伴って宣言されています。このような関数を呼び出す際、出力パラメータには値を代入可能な式を指定する必要があります。出力値が必要ない場合は、特別な引数 `void` を渡すことでコンパイラにその旨を伝えることができます。

```cs
// この関数は出力パラメータで値を返します
void func(int &out outputValue)
{
  outputValue = 42;
}

// 出力値を受け取るために有効な左辺値の式で関数を呼び出します
int value;
func(value);

// 出力値を無視するために 'void' 引数で関数を呼び出します
func(void);
```

引数に名前を付け、パラメータが宣言された順序に関わらず特定の引数に渡すことも可能です。名前付き引数の後に位置引数（名前のない引数）を置くことはできません。

```cs
void func(int flagA = false, int flagB = false, int flagC = false) {}

// パラメータのサブセットのみを設定して関数を呼び出します
func(flagC: true);
func(flagB: true, flagA: true);
```

関数テンプレートでは、コンパイラが呼び出すべき正しい関数テンプレートインスタンスを評価できるよう、サブタイプを明示的に指定する必要があります：

```cs
templ<int,float>(arg1, arg2);
```

## 算術演算子 (Math operators)

```cs
c = -(a + b);
```

| 演算子 | 説明          | 左辺 | 右辺 | 結果 |
|--------|-------------|------|------|------|
| `+`    | 単項正      |      | NUM  | NUM  |
| `-`    | 単項負      |      | NUM  | NUM  |
| `+`    | 加算        | NUM  | NUM  | NUM  |
| `-`    | 減算        | NUM  | NUM  | NUM  |
| `*`    | 乗算        | NUM  | NUM  | NUM  |
| `/`    | 除算        | NUM  | NUM  | NUM  |
| `%`    | 剰余（モジュロ）| NUM  | NUM  | NUM  |
| `**`   | べき乗      | NUM  | NUM  | NUM  |

`+` と `-` は単項演算子としても使用できます。`NUM` は `int` や `float` などの数値型を表します。二項演算では、両辺の型が異なる場合、暗黙的に同じ型へ変換された上で計算されます。結果の型は元のオペランドと同じ型になります。ただし、単項負数演算（`-`）は `uint` 型には使用できない点に注意してください。

## ビット演算子 (Bitwise operators)

```cs
c = ~(a | b);
```

| 演算子  | 説明              | 左辺 | 右辺 | 結果 |
|---------|-----------------|------|------|------|
| `~`     | ビット補数        |      | NUM  | NUM  |
| `&`     | ビット AND       | NUM  | NUM  | NUM  |
| `\|`    | ビット OR        | NUM  | NUM  | NUM  |
| `^`     | ビット XOR       | NUM  | NUM  | NUM  |
| `<<`    | 左シフト          | NUM  | NUM  | NUM  |
| `>>`    | 右シフト          | NUM  | NUM  | NUM  |
| `>>>`   | 算術右シフト      | NUM  | NUM  | NUM  |

`~` 以外はすべて二項演算子です。両方のオペランドは、演算前に（符号を維持したまま）整数型に変換されます。結果の型は左辺のオペランドと同じ型になります。

## 複合代入 (Compound assignments)

```cs
lvalue += rvalue;
lvalue = lvalue + rvalue;
```

複合代入は、演算と代入を組み合わせた記述形式です。上記の2つの式は論理的には同じですが、前者（`+=`）の方が `lvalue` の評価が1回で済むため、特に `lvalue` が複雑な式である場合に効率的です。

利用可能な演算子: `+= -= *= /= %= **= &= |= ^= <<= >>= >>>=`

## 論理演算子 (Logic operators)

```cs
if( a and b or not c )
{
  // ... 何かを行います
}
```

| 演算子 | 説明         | 左辺   | 右辺   | 結果   |
|--------|------------|--------|--------|--------|
| `not`  | 論理 NOT   |        | bool   | bool   |
| `and`  | 論理 AND   | bool   | bool   | bool   |
| `or`   | 論理 OR    | bool   | bool   | bool   |
| `xor`  | 論理排他 OR| bool   | bool   | bool   |

論理演算子は「短絡評価（ショートサーキット）」を行います。例えば `a and b` という式において、`a` が `false` であれば、結果は必ず `false` になるため `b` は評価されません。

各論理演算子は記号で書くこともできます：`or` は `||`、`and` は `&&`、`xor` は `^^`、`not` は `!`。

## 等値比較演算子 (Equality comparison operators)

```cs
if( a == b )
{
  // ... 何かを行います
}
```

演算子 `==` と `!=` は2つの値が等しいかどうかを比較するために使用されます。この演算の結果は常にブール値です。

## 関係比較演算子 (Relational comparison operators)

```cs
if( a > b )
{
  // ... 何かを行います
}
```

演算子 `<`、`>`、`<=`、`>=` は、2つの値の大小関係を比較します。結果は常にブール値（`true` または `false`）になります。

## 同一性比較演算子 (Identity comparison operators)

```cs
if( a is null )
{
  // ... 何かを行います
}
else if( a is b )
{
  // ... 何かを行います
}
```

演算子 `is` と `!is` は、2つのオブジェクトの「同一性」を比較します。つまり、それらがメモリ上の全く同じインスタンスを指しているかどうかを判定します。これらの演算子はオブジェクトのアドレスを比較するため、参照型に対してのみ有効です。結果は常にブール値になります。

## インクリメント演算子 (Increment operators)

```cs
// 以下は a = i; i = i + 1; を意味します
a = i++;

// 以下は i = i - 1; b = i; を意味します
b = --i;
```

これらの演算子を `lvalue` の前または後に置くことで、変数の値を 1 だけ増やしたり（インクリメント）、減らしたり（デクリメント）できます。前置（`++i`）か後置（`i++`）かによって、式全体の中で「いつ」値が更新されるかが決まります。

## インデックス演算子 (Indexing operator)

```cs
arr[i] = 1;
```

この演算子はオブジェクト内に含まれる要素にアクセスするために使用されます。オブジェクト型に応じて、`[]` 内の式は異なる型である必要があります。

## 条件式 (Conditional expression)

```cs
choose ? a : b;
```

`choose` の値が `true` の場合、式は `a` を返し、そうでない場合は `b` を返します。

`a` と `b` は同じ型である必要があります。型が異なる場合、コンパイラは「最小コストの原則」（[関数オーバーロードの引数マッチング](./doc_script_function#引数のマッチング-argument-matching) と同様のルール）に従って、どちらかの式をもう一方へと暗黙的に変換しようと試みます。

`a` と `b` の両方が同じ型の lvalue である場合は、条件式を代入式の左辺として使用することができます：

```cs
int a, b;
(expr ? a : b) = 42;
```

## メンバーアクセス (Member access)

```cs
object.property = 1;
object.method();
```

`object` はメンバーを持つデータ型に評価される式でなければなりません。`property` は直接読み書きできるメンバー変数の名前です。`method` はオブジェクトで呼び出すことができるメンバーメソッドの名前です。

## ハンドル (Handle-of)

```cs
// ハンドルがオブジェクトインスタンスを参照するようにします
@handle = @object;

// ハンドルをクリアし参照しているオブジェクトを解放します
@handle = null;
```

オブジェクトハンドルはオブジェクトへの参照です。複数のハンドルが同じオブジェクトを参照することができ、オブジェクトを参照するハンドルがなくなった時にのみオブジェクトは破棄されます。

ハンドルが参照するオブジェクトのメンバーは、オブジェクト変数を通じて直接アクセスするのと同じように、`.` 演算子を通じてハンドルを介してアクセスされます。

参照: [スクリプトのハンドル](./doc_script_handle)

## 括弧 (Parenthesis)

```cs
a = c * (a + b);
if( (a or b) and c )
{
  // ... 何かを行います
}
```

括弧は [演算子の優先順位](./doc_script_precedence) が望む評価の順序を与えない場合に式をグループ化するために使用されます。

## スコープ解決 (Scope resolution)

```cs
int value;
void function()
{
  int value;        // ローカル変数がグローバル変数をオーバーロードします
  ::value = value;  // スコープ解決演算子を使ってグローバル変数を参照します
}
```

スコープ解決演算子 `::` を使用すると、同じ名前のローカル変数が存在する場合でも、グローバルスコープなどの別のスコープにある変数や関数にアクセスできます。演算子の左側に名前空間などのスコープ名（グローバルスコープの場合は空）を、右側にアクセスしたい名前を記述します。

参照: [名前空間](./doc_script_global#名前空間-namespaces)

## 型変換 (Type conversions)

```cs
// クラスのハンドルをインターフェースのハンドルに暗黙的に変換します
intf @a = @clss();

// インターフェースのハンドルをクラスのハンドルに明示的に変換します
clss @b = cast<clss>(a);
```

オブジェクトハンドルは `cast` 演算子を使用して、別のオブジェクト型（クラスやインターフェース）のハンドルへと変換できます。このキャストが有効な場合（実際のオブジェクトが要求された型を継承または実装している場合）、新しいハンドルが返されます。無効な場合は `null` が返されます。

上記は参照キャストと呼ばれ、オブジェクトハンドルをサポートする型に対してのみ機能します。この場合ハンドルは依然として同じオブジェクトを参照していて、単に異なるインターフェースを通じて公開されているだけです。

通常、プリミティブ型や値型同士の変換には「値キャスト」が用いられます。この場合、元の値に基づいて新しい値が生成されます（または新しいインスタンスが作成されます）。

```cs
// 暗黙の値キャスト
int a = 1.0f;

// 明示的な値キャスト
float b = float(a)/2;
```

コンパイラが通常正しい型への暗黙のキャストを行うことができるため、ほとんどの場合プリミティブ型では明示的なキャストは必要ありません。

## 匿名オブジェクト (Anonymous objects)

変数として宣言せずにその場でオブジェクトを作成する（匿名オブジェクト）には、コンストラクタを関数のように呼び出します。これは参照型と値型のどちらでも可能です。

```cs
// MyClass 型の新しいオブジェクトで関数を呼び出します
func(MyClass(1,2,3));
```

サポートする型では、匿名オブジェクトを初期化リストで初期化することもできます：

```cs
// dictionary を使って関数を呼び出し、初期化リストの型を明示的に指定します
func(dictionary = {{'banana',1}, {'apple',2}, {'orange',3}});

// 初期化リストをサポートする型が1つしかない場合、型を省略して
// コンパイラに使用方法に基づいて暗黙的に決定させることが可能です
funcExpectsAnArrayOfInts({1,2,3,4});
```

望む匿名オブジェクトの型がテンプレートである場合、テンプレート型を明示的に指定する必要があるかもしれません：

```cs
funcExpectsAnArray(array<int> = {1,2,3,4});
```
