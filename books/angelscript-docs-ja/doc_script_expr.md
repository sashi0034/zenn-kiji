## 代入 (Assignments)

```cs
lvalue = rvalue;
```

`lvalue` は式の値を格納できるメモリの場所（例えば変数）に評価される式でなければなりません。代入は格納されたデータと同じ値と型に評価されます。右辺の式は常に左辺の前に計算されます。

## 関数呼び出し (Function call)

```cs
func();
func(arg);
func(arg1, arg2);
lvalue = func();
```

関数はアクションを実行するために呼び出され、さらなる操作で使用できる値を返す可能性があります。関数が複数の引数を取る場合、引数式は逆順（つまり最後の引数が最初に評価される）で評価されます。

一部の関数は複数の値を返すために出力参照パラメータを持って宣言されています。そのような関数を呼び出す際、出力パラメータは返された値が代入される式として与えなければなりません。追加の出力値が使用されない場合は、特別な引数 `void` を使用してコンパイラに伝えてください。

```cs
// この関数は出力パラメータで値を返します
void func(int &out outputValue)
{
  outputValue = 42;
}

// 出力値を受け取るために有効な左辺値の式で関数を呼び出します
int value;
func(value);

// 出力値を無視するために 'void' 引数で関数を呼び出します
func(void);
```

引数に名前を付け、パラメータが宣言された順序に関わらず特定の引数に渡すことも可能です。名前付き引数の後に位置引数は来られません。

```cs
void func(int flagA = false, int flagB = false, int flagC = false) {}

// パラメータのサブセットのみを設定して関数を呼び出します
func(flagC: true);
func(flagB: true, flagA: true);
```

関数テンプレートでは、コンパイラが呼び出すべき正しい関数テンプレートインスタンスを評価できるよう、サブタイプを明示的に指定する必要があります：

```cs
templ<int,float>(arg1, arg2);
```

## 算術演算子 (Math operators)

```cs
c = -(a + b);
```

| 演算子 | 説明          | 左辺 | 右辺 | 結果 |
|--------|-------------|------|------|------|
| `+`    | 単項正      |      | NUM  | NUM  |
| `-`    | 単項負      |      | NUM  | NUM  |
| `+`    | 加算        | NUM  | NUM  | NUM  |
| `-`    | 減算        | NUM  | NUM  | NUM  |
| `*`    | 乗算        | NUM  | NUM  | NUM  |
| `/`    | 除算        | NUM  | NUM  | NUM  |
| `%`    | 剰余（モジュロ）| NUM  | NUM  | NUM  |
| `**`   | べき乗      | NUM  | NUM  | NUM  |

`+` と `-` は単項演算子としても使用できます。NUM は `int` や `float` などの数値型で置き換えられます。二項演算の両辺は暗黙的に同じ型に変換されます。結果は常に元のオペランドと同じ型です。例外として単項負は `uint` では使用できません。

## ビット演算子 (Bitwise operators)

```cs
c = ~(a | b);
```

| 演算子  | 説明              | 左辺 | 右辺 | 結果 |
|---------|-----------------|------|------|------|
| `~`     | ビット補数        |      | NUM  | NUM  |
| `&`     | ビット AND       | NUM  | NUM  | NUM  |
| `\|`    | ビット OR        | NUM  | NUM  | NUM  |
| `^`     | ビット XOR       | NUM  | NUM  | NUM  |
| `<<`    | 左シフト          | NUM  | NUM  | NUM  |
| `>>`    | 右シフト          | NUM  | NUM  | NUM  |
| `>>>`   | 算術右シフト      | NUM  | NUM  | NUM  |

`~` 以外はすべて二項演算子です。両オペランドは演算前に符号を保ちながら整数に変換されます。結果の型は左辺のオペランドと同じです。

## 複合代入 (Compound assignments)

```cs
lvalue += rvalue;
lvalue = lvalue + rvalue;
```

複合代入は演算子と代入の組み合わせです。上記の2つの式は実質的に同じです。ただし前者の方が lvalue が1回のみ評価されるためより効率的で、lvalue 自体が複雑な式である場合に差が出ます。

利用可能な演算子: `+= -= *= /= %= **= &= |= ^= <<= >>= >>>=`

## 論理演算子 (Logic operators)

```cs
if( a and b or not c )
{
  // ... 何かを行います
}
```

| 演算子 | 説明         | 左辺   | 右辺   | 結果   |
|--------|------------|--------|--------|--------|
| `not`  | 論理 NOT   |        | bool   | bool   |
| `and`  | 論理 AND   | bool   | bool   | bool   |
| `or`   | 論理 OR    | bool   | bool   | bool   |
| `xor`  | 論理排他 OR| bool   | bool   | bool   |

ブール演算子は必要な項のみを評価します。例えば `a and b` の式では、`a` が `true` の場合にのみ `b` が評価されます。

各論理演算子は記号で書くこともできます：`or` は `||`、`and` は `&&`、`xor` は `^^`、`not` は `!`。

## 等値比較演算子 (Equality comparison operators)

```cs
if( a == b )
{
  // ... 何かを行います
}
```

演算子 `==` と `!=` は2つの値が等しいかどうかを比較するために使用されます。この演算の結果は常にブール値です。

## 関係比較演算子 (Relational comparison operators)

```cs
if( a > b )
{
  // ... 何かを行います
}
```

演算子 `<`、`>`、`<=`、`>=` は2つの値の関係を決定するために比較します。結果は常にブール値です。

## 同一性比較演算子 (Identity comparison operators)

```cs
if( a is null )
{
  // ... 何かを行います
}
else if( a is b )
{
  // ... 何かを行います
}
```

演算子 `is` と `!is` は2つのオブジェクトの同一性を比較するために使用されます。つまり、2つが同じオブジェクトかどうかを決定します。これらの演算子は2つのオブジェクトのアドレスを比較するため参照型にのみ有効です。結果は常にブール値です。

## インクリメント演算子 (Increment operators)

```cs
// 以下は a = i; i = i + 1; を意味します
a = i++;

// 以下は i = i - 1; b = i; を意味します
b = --i;
```

これらの演算子を lvalue の前または後に置くことで、値が式で使用される前または後にその値を増分/減分することができます。値は常に 1 だけ増分または減分されます。

## インデックス演算子 (Indexing operator)

```cs
arr[i] = 1;
```

この演算子はオブジェクト内に含まれる要素にアクセスするために使用されます。オブジェクト型に応じて、`[]` 内の式は異なる型である必要があります。

## 条件式 (Conditional expression)

```cs
choose ? a : b;
```

`choose` の値が `true` の場合、式は `a` を返し、そうでない場合は `b` を返します。

`a` と `b` は同じ型でなければなりません。そうでない場合、コンパイラは最小コストの原則（[関数呼び出しの引数マッチング](./doc_script_function#引数のマッチング-argument-matching) と同様の方法でコストが決定されます）に従って暗黙の変換を試みます。

`a` と `b` の両方が同じ型の lvalue である場合は、条件式を代入式の左辺として使用することができます：

```cs
int a, b;
(expr ? a : b) = 42;
```

## メンバーアクセス (Member access)

```cs
object.property = 1;
object.method();
```

`object` はメンバーを持つデータ型に評価される式でなければなりません。`property` は直接読み書きできるメンバー変数の名前です。`method` はオブジェクトで呼び出すことができるメンバーメソッドの名前です。

## ハンドル (Handle-of)

```cs
// ハンドルがオブジェクトインスタンスを参照するようにします
@handle = @object;

// ハンドルをクリアし参照しているオブジェクトを解放します
@handle = null;
```

オブジェクトハンドルはオブジェクトへの参照です。複数のハンドルが同じオブジェクトを参照することができ、オブジェクトを参照するハンドルがなくなった時にのみオブジェクトは破棄されます。

ハンドルが参照するオブジェクトのメンバーは、オブジェクト変数を通じて直接アクセスするのと同じように、`.` 演算子を通じてハンドルを介してアクセスされます。

参照: [スクリプトのハンドル](./doc_script_handle)

## 括弧 (Parenthesis)

```cs
a = c * (a + b);
if( (a or b) and c )
{
  // ... 何かを行います
}
```

括弧は [演算子の優先順位](./doc_script_precedence) が望む評価の順序を与えない場合に式をグループ化するために使用されます。

## スコープ解決 (Scope resolution)

```cs
int value;
void function()
{
  int value;        // ローカル変数がグローバル変数をオーバーロードします
  ::value = value;  // スコープ解決演算子を使ってグローバル変数を参照します
}
```

スコープ解決演算子 `::` は、名前がローカル変数や関数によってオーバーロードされている場合に別のスコープから変数や関数にアクセスするために使用できます。左にスコープ名（またはグローバルスコープのために空白）を書き、右に変数/関数の名前を書きます。

参照: [名前空間](./doc_script_global#名前空間-namespaces)

## 型変換 (Type conversions)

```cs
// クラスのハンドルをインターフェースのハンドルに暗黙的に変換します
intf @a = @clss();

// インターフェースのハンドルをクラスのハンドルに明示的に変換します
clss @b = cast<clss>(a);
```

オブジェクトハンドルは `cast` 演算子で他のオブジェクトハンドルに変換することができます。キャストが有効（つまり真のオブジェクトが要求されているクラスまたはインターフェースを実装している）場合、演算子は有効なハンドルを返します。キャストが有効でない場合、キャストは null ハンドルを返します。

上記は参照キャストと呼ばれ、オブジェクトハンドルをサポートする型に対してのみ機能します。この場合ハンドルは依然として同じオブジェクトを参照していて、単に異なるインターフェースを通じて公開されているだけです。

オブジェクトハンドルをサポートしない型は代わりに値キャストで変換できます。この場合、新しい値が構築されるか、オブジェクトの場合はそのオブジェクトの新しいインスタンスが作成されます。

```cs
// 暗黙の値キャスト
int a = 1.0f;

// 明示的な値キャスト
float b = float(a)/2;
```

コンパイラが通常正しい型への暗黙のキャストを行うことができるため、ほとんどの場合プリミティブ型では明示的なキャストは必要ありません。

## 匿名オブジェクト (Anonymous objects)

変数として宣言されずに作成されるオブジェクト（匿名オブジェクト）は、オブジェクトのコンストラクタを関数であるかのように呼び出すことで式内でインスタンス化できます。参照型と値型の両方をこのように作成できます。

```cs
// MyClass 型の新しいオブジェクトで関数を呼び出します
func(MyClass(1,2,3));
```

サポートする型では、匿名オブジェクトを初期化リストで初期化することもできます：

```cs
// dictionary を使って関数を呼び出し、初期化リストの型を明示的に指定します
func(dictionary = {{'banana',1}, {'apple',2}, {'orange',3}});

// 初期化リストをサポートする型が1つしかない場合、型を省略して
// コンパイラに使用方法に基づいて暗黙的に決定させることが可能です
funcExpectsAnArrayOfInts({1,2,3,4});
```

望む匿名オブジェクトの型がテンプレートである場合、テンプレート型を明示的に指定する必要があるかもしれません：

```cs
funcExpectsAnArray(array<int> = {1,2,3,4});
```
