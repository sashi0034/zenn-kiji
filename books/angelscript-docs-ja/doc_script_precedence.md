---
title: "演算子の優先順位 (Operator precedence)"
---

式では、最も高い優先順位を持つ演算子が常に最初に計算されます。

## 単項演算子 (Unary operators)

単項演算子は他の演算子よりも高い優先順位を持ち、単項演算子の間では実際の値に最も近い演算子が最も高い優先順位を持ちます。後置演算子は前置演算子より高い優先順位を持ちます。

以下は利用可能な単項演算子の一覧です（優先順位の高い順）：

| 演算子 | 説明 |
|--------|------|
| `::` | スコープ解決演算子 |
| `[]` | インデックス演算子 |
| `++ --` | 後置インクリメント・デクリメント |
| `.` | メンバーアクセス |
| `++ --` | 前置インクリメント・デクリメント |
| `not !` | 論理 NOT |
| `+ -` | 単項正・負 |
| `~` | ビット補数 |
| `@` | ハンドル of |

## 二項・三項演算子 (Binary and ternary operators)

以下は二項演算子と三項演算子の優先順位を降順で示しています：

| 演算子 | 説明 |
|--------|------|
| `**` | べき乗 |
| `* / %` | 乗算、除算、剰余 |
| `+ -` | 加算、減算 |
| `<< >> >>>` | 左シフト、右シフト、算術右シフト |
| `&` | ビット AND |
| `^` | ビット XOR |
| `\|` | ビット OR |
| `<= < >= >` | 比較 |
| `== != is !is xor ^^` | 等値、同一性、論理排他 OR |
| `and &&` | 論理 AND |
| `or \|\|` | 論理 OR |
| `?:` | 条件 |
| `= += -= *= /= %= **= &= \|= ^= <<= >>= >>>=` | 代入と複合代入 |
