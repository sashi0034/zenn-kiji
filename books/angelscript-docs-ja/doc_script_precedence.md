---
title: "演算子の優先順位 (Operator precedence)"
---

式の中に複数の演算子が含まれる場合、常に優先順位の高い演算子から先に計算されます。

## 単項演算子 (Unary operators)

単項演算子は他の演算子（二項演算子など）よりも高い優先順位を持ちます。複数の単項演算子が並んでいる場合は、対象の値に最も近いものから順に適用されます。また、後置演算子（`a++` など）は前置演算子（`++a` など）よりも優先順位が高くなります。

以下は利用可能な単項演算子の一覧です（優先順位の高い順）：

| 演算子 | 説明 |
|--------|------|
| `::` | スコープ解決演算子 |
| `[]` | インデックス演算子 |
| `++ --` | 後置インクリメント・デクリメント |
| `.` | メンバーアクセス |
| `++ --` | 前置インクリメント・デクリメント |
| `not !` | 論理 NOT |
| `+ -` | 単項正・負 |
| `~` | ビット補数 |
| `@` | ハンドル of |

## 二項・三項演算子 (Binary and ternary operators)

以下は、二項演算子および三項演算子の優先順位を高い順（降順）に示したものです。

| 演算子 | 説明 |
|--------|------|
| `**` | べき乗 |
| `* / %` | 乗算、除算、剰余 |
| `+ -` | 加算、減算 |
| `<< >> >>>` | 左シフト、右シフト、算術右シフト |
| `&` | ビット AND |
| `^` | ビット XOR |
| `\|` | ビット OR |
| `<= < >= >` | 比較 |
| `== != is !is xor ^^` | 等値、同一性、論理排他 OR |
| `and &&` | 論理 AND |
| `or \|\|` | 論理 OR |
| `?:` | 条件 |
| `= += -= *= /= %= **= &= \|= ^= <<= >>= >>>=` | 代入と複合代入 |
