---
title: "単一参照の型の登録 (Registering a single-reference type)"
---

インスタンス化不可能な参照型のバリエーションの1つに、「単一参照の型 (single-reference type)」があります。これは、その型にアクセスしている参照が1つしか存在しない型、すなわち、スクリプトが実行中にそのオブジェクトへの余分な参照を保存できない型です。スクリプトは、アプリケーションがスクリプトに参照を渡したその瞬間に受け取った参照を使用するよう強制されます。

参照は、グローバルまたはクラスメンバのプロパティを通じてスクリプトに渡されるか、アプリケーションから登録された関数やクラスメソッドから返されることで渡されます。

スクリプトエンジンは、この型をパラメータとして（参照としてもハンドルとしても）受け取る関数の宣言を許可しません。もしそれが許可された場合、インスタンスへの参照がスタックに配置されることになり、もはや単一参照の型ではなくなってしまうからです。

```cpp
// スクリプトによってインスタンス化されず、
// スクリプトがこの型への参照を保存することも許可しないように型を登録する
r = engine->RegisterObjectType("single", 0, asOBJ_REF | asOBJ_NOHANDLE); assert( r >= 0 );
```

この種の型は、オブジェクトへの参照を完全に制御したい場合に最も役立ちます。例えば、スクリプトによって保持されている可能性のある参照について心配することなく、アプリケーションがその型のオブジェクトを破棄して再作成できるようにするためです。これにより、アプリケーションはスクリプトがいつオブジェクトやそのメンバにアクセスできるかを制御可能になります。
