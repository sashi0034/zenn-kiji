---
title: "単一参照の型の登録 (Registering a single-reference type)"
---

インスタンス化不可能な参照型のバリエーションとして、「単一参照型（Single-Reference Type）」があります。これは、そのオブジェクトへの有効な参照が常に一つしか存在しないことを保証する型です。つまり、スクリプトは実行中にこのオブジェクトへの追加の参照を保存することはできません。スクリプトは、アプリケーションから提供された瞬間にその参照を直接使用することしかできません。

この参照は、グローバル変数やクラスメンバのプロパティとして公開されるか、あるいは登録された関数やメソッドの戻り値としてスクリプトに渡されます。

スクリプトエンジンは、この型を関数の引数として宣言することを（参照渡しであってもハンドルであっても）禁止します。もし許可してしまうと、スタック上にオブジェクトへの参照が置かれることになり、結果として「単一参照」ではなくなってしまうためです。

```cpp
// スクリプトによってインスタンス化されず、
// スクリプトがこの型への参照を保存することも許可しないように型を登録する
r = engine->RegisterObjectType("single", 0, asOBJ_REF | asOBJ_NOHANDLE); assert( r >= 0 );
```

この種の型は、オブジェクトへの参照を完全に制御したい場合に最も役立ちます。例えば、スクリプトによって保持されている可能性のある参照について心配することなく、アプリケーションがその型のオブジェクトを破棄して再作成できるようにするためです。これにより、アプリケーションはスクリプトがいつオブジェクトやそのメンバにアクセスできるかを制御可能になります。
