---
title: "オブジェクトハンドル (Object handles)"
---

オブジェクトハンドルは、オブジェクトへの参照（ポインタのようなもの）を保持するための型です。ハンドルを使用することで、複数の変数から同一の物理オブジェクトを参照・操作することが可能になります。

すべての型でハンドルが使えるわけではありません。`bool`, `int`, `float` などのプリミティブ型はハンドルを持てません。アプリケーションが登録したカスタムオブジェクト型については、その登録時の設定によってハンドルの可否が決まります。

参照: [アプリケーションへのオブジェクトハンドル](./doc_obj_handle)

## 基本的な使用法 (General usage)

オブジェクトハンドルはデータ型に `@` シンボルを追加することで宣言されます。

```cs
object@ obj_h;
```

このコードはオブジェクトハンドル `obj_h` を宣言し、`null`（どのオブジェクトも指していない状態）で初期化します。

式の中では、ハンドルとして宣言された変数は通常のオブジェクトと全く同じように記述できます。ただし、ハンドルが実際に有効なオブジェクトを指している保証はないため、`null` 状態のハンドルを通じてメンバにアクセスしようとすると例外が発生します。

```cs
object obj;
object@ obj_h;
obj.Method();
obj_h.Method();
```

`=` 演算子や、そのオブジェクト型に定義されている他の演算子は、ハンドルが指している **実体（オブジェクト）** に対して作用します。ハンドルが空の場合、これらの操作も例外をスローします。

```cs
object obj;
object@ obj_h;
obj_h = obj;
```

実際のハンドルに対する操作が必要な場合は、式の前に `@` シンボルを付ける必要があります。オブジェクトハンドルをオブジェクトを指すように設定するには例えば次のようにします：

```cs
object obj;
object@ obj_h;
@obj_h = @obj;
```

コンパイラは多くの場合、実体ではなくハンドルそのものが必要であることを文脈から推論できます。そのようなケースでは `@` を明示する必要はありません。

ハンドル同士を比較して、それらが「同じインスタンスを指しているか」を確認することもできます。また、空のハンドルを示す `null` キーワードと比較することも可能です。これには同一性演算子 `is` または `!is` を使用します。

```cs
object@ obj_a, obj_b;
if( obj_a is obj_b ) {}
if( obj_a !is null ) {}
```

`==` および `!=` 演算子は、`opEquals` や `opCmp` オーバーロードを使用して、ハンドルが指すオブジェクトの **値** を比較します。一方、式の前に `@` を付けた場合は、これらの演算子も `is` / `!is` と同様に「同一インスタンスかどうか」を判定するようになります。

## オブジェクトのライフタイム (Object life times)

オブジェクトのライフタイムは通常、変数が宣言されたスコープの期間です。しかし、スコープ外のハンドルがオブジェクトを参照するよう設定されている場合、オブジェクトはすべてのオブジェクトハンドルが解放されるまで生き続けます。

```cs
object@ obj_h;
{
  object obj;
  @obj_h = @obj;

  // オブジェクトはブロックが終了する時に通常消滅しますが、
  // ハンドルはまだそれへの参照を保持しています
}

// オブジェクトは obj_h の中でまだ生きています...
obj_h.Method();

// ...参照が明示的に解放されるか、
// オブジェクトハンドルがスコープ外に出るまで
@obj_h = null;
```

## オブジェクトの関係とポリモーフィズム (Object relations and polymorphing)

オブジェクトハンドルは、継承やインターフェースにより、関連する型の共通コードを書くために使用できます。これにより、インターフェースへのハンドルがそのインターフェースを実装するすべてのオブジェクト型への参照を格納できるようになり、同様に基底クラスへのハンドルがその基底クラスから派生するすべてのオブジェクト型への参照を格納できるようになります。

```cs
interface I {}
class A : I {}
class B : I {}

// インターフェースへのハンドルに参照を格納します
I @i1 = A();  
I @i2 = B();  

void function(I @i)
{ 
  // インターフェースによって実装されたメソッドはインターフェースハンドルを通じて
  // 直接呼び出すことができます。しかし特定の型に対して特別な処理が必要な場合、
  // キャストを使用して真の型へのハンドルを取得することができます
  A @a = cast<A>(i);
  if( a !is null )
  {
    // A のメンバーに直接アクセスします
    ...
  }
  else
  { 
    // i で参照されるオブジェクトは A 型ではありません
    ...
  }
}
```

## const ハンドル (Const handles)

変更を許可していないオブジェクトへのハンドルを保持する必要がある場合があります。型の前に `const` を付けることで行います：

```cs
obj @a;                      // 変更可能なオブジェクトへのハンドル
const obj @b;                // 変更不可能なオブジェクトへのハンドル
```

変更不可能なオブジェクトへのハンドルは変更可能なオブジェクトと変更不可能なオブジェクトの両方を参照できますが、スクリプトはそのハンドルを通じてオブジェクトを変更すること、またはハンドルを変更を許可する別のハンドルに渡すことを許可しません。

この構文は、ハンドル自体が読み取り専用（つまりハンドルが別のオブジェクトを参照するように再代入できない）の場合と混同しないでください。このような読み取り専用ハンドルは `@` シンボルの後にサフィックスとして `const` キーワードを追加することで宣言されます：

```cs
obj @ const c = obj();       // 変更可能なオブジェクトへの読み取り専用ハンドル
const obj @ const d = obj(); // 変更不可能なオブジェクトへの読み取り専用ハンドル
```

読み取り専用ハンドルは宣言時にのみ初期化できます。
