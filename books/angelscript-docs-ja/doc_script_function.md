## グローバル関数の宣言

グローバル関数は、特定の入力を受け取り、何らかの処理を行って結果を返すルーチンを実装するために使用されます。関数自体は状態（メモリ）を保持しませんが、グローバル変数の書き換えや、参照渡しされたメモリの更新を行うことは可能です。

関数は常に実体（関数本体）と共に宣言されます。AngelScript のコンパイラは宣言場所に関わらず関数をグローバルに認識するため、C++ のような関数プロトタイプの先読み宣言は不要です。

```cs
// シンプルな関数宣言
int AFunction(int a, int b)
{
  // 関数のロジックをここに実装します
  return a + b;
}
```

戻り値の型は関数名の前に指定します。関数が何も返さない場合、型は `void` として定義します。関数名の後、パラメータのリストが括弧内に指定されます。各パラメータはその型と名前によって定義されます。

## パラメータの参照 (Parameter references)

パラメータ（引数）と戻り値には、変数宣言で使用可能なあらゆる型を指定できます。さらに、関数が値を **参照渡し** で受け取るように設定することも可能です。この場合、元の値のコピーではなく、元の値そのものを指す参照が渡されます。

参照パラメータは主に2つの目的で使用されます。一つは関数から複数の値を返すための追加の出力手段として、もう一つは（コピーを避けることで）大きな値を効率的に渡すためです。

AngelScript では、参照の意図（入力用、出力用、あるいはその両方）を明示する必要があります。これは、関数の実行中に参照先が無効化されないよう、コンパイラが適切に準備を行うために考案された仕組みです。

入力参照は `&in` と記述します。これは入力のみを目的としているため、通常は元の値のコピーが参照先に渡されます。これにより、関数が誤って呼び出し元の値を書き換えてしまうのを防ぎます。値渡しと比べてメリットが少ないため、多用はされませんが、パラメータを `const` 指定した場合には特定の状況でパフォーマンスが向上することがあります。

出力参照は `&out` と記述します。関数から追加の結果を返すために使用され、関数開始時には初期化されていない値を指しています。関数が終了すると、その値が呼び出し元の指定した変数へコピーされます。

入力と出力の両方を意図する場合は `&inout`（または単に `&`）と宣言します。この場合、参照は実際のメモリ上の値を直接指します。関数の実行中、参照先が常に有効であることを保証する必要があるため、参照先はヒープ上に存在しなければなりません。そのため、inout 参照として渡せるのは、ハンドルをサポートする [参照型](./doc_script_datatypes#オブジェクト-objects) に限定されます。

```cs
void Function(const int &in a, int &out b, Object &c)
{
  // 出力参照に出力値を代入します
  b = a;

  // オブジェクトは inout 参照であり、実際のオブジェクトを参照します
  c.DoSomething();
}
```

## 参照の返却 (Return references)

関数は参照を返すこともでき、呼び出し元が参照先の値を変更できるようになります。参照を返す関数を宣言するには、戻り値の型と関数名の間に `&` 記号を含めます。参照が読み取り専用であるべき（つまりそれが指す値を変更できないようにする）場合は、型の前に `const` を追加します。

```cs
int property;
int &Function()
{
  // プロパティへの参照を返します
  return property;
}

void main()
{
  // 返された参照が指す値を変更します
  Function() = 1;
}
```

関数が呼び出し元に戻った後でも、返された参照が有効であることを保証しなければならないため、いくつかの制約があります。制約に違反した場合はコンパイラがエラーを出すため、すべてを暗記する必要はありませんが、エラーの原因を理解しておくことは解決の助けになります。

- **グローバル変数への参照は許可されます**: グローバル変数はプログラムの実行中ずっと存在するため、関数の終了後も参照が有効です。
- **クラスメンバーへの参照は許可されます**: クラスのメソッドは、そのオブジェクト自身のプロパティへの参照を返すことができます。呼び出し元はそのオブジェクトへの参照を保持しているはずなので、メソッド終了後もメンバーが存在することが保証されます。
- **ローカル変数への参照は返せません**: ローカル変数は関数終了時に破棄されるため、それらへの参照を戻り値にすることは禁止されています。関数のパラメータについても同様です。
- **遅延パラメータを伴う式は使用できません**: 一部の関数呼び出しでは、呼び出し終了後に追加の処理（出力パラメータの書き戻しなど）が必要な場合があります。そのような処理の影響で参照が無効になる可能性があるため、参照を返す関数内でそうした引数を含む式の評価結果をそのまま返すことはできません。

## 関数オーバーロード (Function overloading)

関数オーバーロードは、同じ名前の関数が異なるパラメータで複数宣言された場合に起こります。これは操作が異なる入力型で動作できる必要がある場合に便利な機能です。

コンパイラは各引数式の型を関数パラメータに一致させ、変換が不可能な関数を除外することで、どの関数を呼び出すかを解決することができます。すべての引数が評価された後、最良の一致となる関数は1つだけであるはずで、そうでない場合コンパイラは正しい関数を呼び出せないというエラーを報告します。

変換のタイプの優先順位（高い方がより良い一致）：
1. 変換不要
2. const への変換
3. 同じサイズの整数への enum の変換
4. 異なるサイズの整数への enum の変換
5. プリミティブ型のサイズが増加
6. プリミティブ型のサイズが減少
7. 符号付き整数から符号なし整数への変換
8. 符号なし整数から符号付き整数への変換
9. 整数型から浮動小数点型へ
10. 浮動小数点型から整数型へ
11. 参照キャスト
12. オブジェクトからプリミティブへの変換
13. オブジェクトへの変換
14. 可変引数型

```cs
void Function(int a, float b, string c) {}
void Function(string a, int b, float c) {}
void Function(float a, string b, int c) {}

void main()
{
  Function(1, 2.5f, 'a');  // 最初のオーバーロードを呼び出します
  Function('a', 1, 2.5f);  // 2番目のオーバーロードを呼び出します
  Function(2.5f, 'a', 1);  // 3番目のオーバーロードを呼び出します
}  
```

戻り値の型のみが異なるオーバーロードを作成することはできません。それはコンパイラがどの関数を呼び出すかを決定するために使用する選択基準の一部でないためです。

## デフォルト引数 (Default arguments)

異なるオーバーロードごとに別々の関数を実装することが不要な場合があります。差異がパラメータのデフォルト値によって提供できる場合です。その場合にデフォルト引数が役立ちます。

関数の宣言でデフォルト引数を定義することで、コンパイラが自動的にデフォルト引数を補完するため、スクリプトは関数を呼び出す際にこれらの値を指定する必要がありません。

```cs
void Function(int a, int b = 1, string c = "")
{
  // 関数内では引数は通常通り動作します
}

void main()
{
  // デフォルト引数は指定する必要はありません
  // 次の3つの呼び出しはまったく同じ結果を生成します
  Function(0);
  Function(0,1);
  Function(0,1,"");
}
```

パラメータの1つにデフォルト引数を定義する場合、それ以降のすべてのパラメータにもデフォルト引数が必要です。

デフォルト引数の式には変数への参照や関数の呼び出しを含めることができますが、変数や関数がグローバルスコープで可視の場合に限ります。

特殊な `void` 式をデフォルト引数として使用して、オプションの出力パラメータを作成することができます：

```cs
void func(int &out output = void) { output = 42; }
```

## 無名関数 (Anonymous functions)

無名関数（ラムダとも呼ばれる）は、[関数ハンドル](./doc_script_datatypes#関数ハンドル-function-handles) と共に使用するためにローカルで宣言される関数です。

```cs
funcdef bool CMP(int first, int second);

void main()
{
  int valueA = 1, valueB = 2;
  
  bool result1 = func(valueA, valueB, function(a,b){ return a == b; });
  bool result2 = func(valueA, valueB, function(a,b){ return a != b; });
}

bool func(int a, int b, CMP @f)
{
  return f(a,b);
}
```

無名関数は、割り当て先の関数ハンドルのシグネチャを自動的に引き継ぐため、引数や戻り値の型を明示的に記述する必要はありません。

現時点では、無名関数が宣言時のスコープにあるローカル変数にアクセスすることはできません（つまり、クロージャとしては機能しません）。

無名関数に対して複数の一致する使い方がある場合、曖昧さを解消できるよう、パラメータ型を明示的に指定する必要があります：

```cs
funcdef void A(int);
funcdef void B(float);
void func(A@) {}
void func(B@) {}

void main()
{
  // A が必要なことをコンパイラに伝えるために型を明示的に指定します
  func(function(int a) {});
}
```
