## グローバル関数の宣言

グローバル関数は、何らかの入力を操作して結果を生成するルーティンを実装する手段を提供します。関数自体はメモリを保持しませんが、グローバル変数や参照渡しされたメモリを更新することができます。

関数は常に関数本体と共に宣言されます。コンパイラはどこで宣言されているかに関わらず関数をグローバルに認識できるため、関数プロトタイプを宣言する必要はありません。

```cs
// シンプルな関数宣言
int AFunction(int a, int b)
{
  // 関数のロジックをここに実装します
  return a + b;
}
```

戻り値の型は関数名の前に指定します。関数が何も返さない場合、型は `void` として定義します。関数名の後、パラメータのリストが括弧内に指定されます。各パラメータはその型と名前によって定義されます。

## パラメータの参照 (Parameter references)

パラメータと戻り値は変数宣言にも使用できる任意の型をとることができます。さらに、関数が値を参照渡しで取るようにすることも可能です。つまり、元の値のコピーではなく、パラメータが値を参照します。

パラメータ参照は主に2つの目的で使用されます：関数からの追加の出力を提供する手段、または値を渡すためのより効率的な方法です。

AngelScript では、パラメータ参照の意図、つまり入力用、出力用、またはその両方のいずれかを指定することが必要です。これは、コンパイラが関数の処理中の何らかのアクションによって参照が無効化されないよう、参照を準備するために必要です。

入力参照は `&in` と書かれます。参照は入力のみを意図しているため、参照する実際の値は通常元のコピーであり、関数が誤って元の値を変更しないようになっています。これらはほとんど使用されません。値渡しの引数に対してほとんどメリットがないからです。特にパラメータが `const` としても宣言されている場合は特定の状況でパフォーマンスが改善されます。

出力参照は `&out` と書かれます。これらの参照は、関数が追加の値を返せるようにするためのものです。関数に入る時、参照は初期化されていない値を指します。関数が返った後、関数が代入した値が呼び出し元によって決定された宛先にコピーされます。

参照が入力と出力の両方を意図する場合、`&inout` または単に `&` と宣言されます。この場合、参照は実際の値を指します。参照は関数の実行全体を通じて有効のままであることを保証するため、ヒープ上にある必要があります。そのため、ハンドルを持つことができる [参照型](./doc_script_datatypes#オブジェクト-objects) のみを inout 参照として渡すことができます。

```cs
void Function(const int &in a, int &out b, Object &c)
{
  // 出力参照に出力値を代入します
  b = a;

  // オブジェクトは inout 参照であり、実際のオブジェクトを参照します
  c.DoSomething();
}
```

## 参照の返却 (Return references)

関数は参照を返すこともでき、呼び出し元が参照先の値を変更できるようになります。参照を返す関数を宣言するには、戻り値の型と関数名の間に `&` 記号を含めます。参照が読み取り専用であるべき（つまりそれが指す値を変更できないようにする）場合は、型の前に `const` を追加します。

```cs
int property;
int &Function()
{
  // プロパティへの参照を返します
  return property;
}

void main()
{
  // 返された参照が指す値を変更します
  Function() = 1;
}
```

関数が呼び出し元に返った後でも参照が有効であることを保証する必要があるため、いくつかの制限があります。コンパイラがこれらの制限が破られた場合にエラーを報告するので記憶しておく必要はありませんが、参照を返す際にコンパイルエラーに遭遇した場合、それを回避する方法を決定できるよう、なぜそれが起きているかを理解するのに役立ちます。

- **グローバル変数への参照は許可されています**: グローバル変数はグローバルスコープにあるため、変数のライフタイムは関数のスコープより長くなります。
- **クラスメンバーへの参照は許可されています**: クラスのメソッドは同じオブジェクトのクラスのプロパティへの参照を返すことができます。呼び出し元はオブジェクトへの参照を保持することが必要なため、メソッドが返った後もメンバーが存在することが分かっています。
- **ローカル変数への参照は返せません**: ローカル変数は関数が終了する際に解放されなければならないため、それらへの参照を返すことはできません。同様のことが関数が受け取ったパラメータにも当てはまります。
- **遅延パラメータを持つ式は使えません**: 引数を持つ一部の関数呼び出しでは、関数呼び出しが返った後に引数の処理が必要な場合があります。参照を返す関数がそのような引数を持つ関数を呼び出している場合、その参照を再び返すことはできません。

## 関数オーバーロード (Function overloading)

関数オーバーロードは、同じ名前の関数が異なるパラメータで複数宣言された場合に起こります。これは操作が異なる入力型で動作できる必要がある場合に便利な機能です。

コンパイラは各引数式の型を関数パラメータに一致させ、変換が不可能な関数を除外することで、どの関数を呼び出すかを解決することができます。すべての引数が評価された後、最良の一致となる関数は1つだけであるはずで、そうでない場合コンパイラは正しい関数を呼び出せないというエラーを報告します。

変換のタイプの優先順位（高い方がより良い一致）：
1. 変換不要
2. const への変換
3. 同じサイズの整数への enum の変換
4. 異なるサイズの整数への enum の変換
5. プリミティブ型のサイズが増加
6. プリミティブ型のサイズが減少
7. 符号付き整数から符号なし整数への変換
8. 符号なし整数から符号付き整数への変換
9. 整数型から浮動小数点型へ
10. 浮動小数点型から整数型へ
11. 参照キャスト
12. オブジェクトからプリミティブへの変換
13. オブジェクトへの変換
14. 可変引数型

```cs
void Function(int a, float b, string c) {}
void Function(string a, int b, float c) {}
void Function(float a, string b, int c) {}

void main()
{
  Function(1, 2.5f, 'a');  // 最初のオーバーロードを呼び出します
  Function('a', 1, 2.5f);  // 2番目のオーバーロードを呼び出します
  Function(2.5f, 'a', 1);  // 3番目のオーバーロードを呼び出します
}  
```

戻り値の型のみが異なるオーバーロードを作成することはできません。それはコンパイラがどの関数を呼び出すかを決定するために使用する選択基準の一部でないためです。

## デフォルト引数 (Default arguments)

異なるオーバーロードごとに別々の関数を実装することが不要な場合があります。差異がパラメータのデフォルト値によって提供できる場合です。その場合にデフォルト引数が役立ちます。

関数の宣言でデフォルト引数を定義することで、コンパイラが自動的にデフォルト引数を補完するため、スクリプトは関数を呼び出す際にこれらの値を指定する必要がありません。

```cs
void Function(int a, int b = 1, string c = "")
{
  // 関数内では引数は通常通り動作します
}

void main()
{
  // デフォルト引数は指定する必要はありません
  // 次の3つの呼び出しはまったく同じ結果を生成します
  Function(0);
  Function(0,1);
  Function(0,1,"");
}
```

パラメータの1つにデフォルト引数を定義する場合、それ以降のすべてのパラメータにもデフォルト引数が必要です。

デフォルト引数の式には変数への参照や関数の呼び出しを含めることができますが、変数や関数がグローバルスコープで可視の場合に限ります。

特殊な `void` 式をデフォルト引数として使用して、オプションの出力パラメータを作成することができます：

```cs
void func(int &out output = void) { output = 42; }
```

## 無名関数 (Anonymous functions)

無名関数（ラムダとも呼ばれる）は、[関数ハンドル](./doc_script_datatypes#関数ハンドル-function-handles) と共に使用するためにローカルで宣言される関数です。

```cs
funcdef bool CMP(int first, int second);

void main()
{
  int valueA = 1, valueB = 2;
  
  bool result1 = func(valueA, valueB, function(a,b){ return a == b; });
  bool result2 = func(valueA, valueB, function(a,b){ return a != b; });
}

bool func(int a, int b, CMP @f)
{
  return f(a,b);
}
```

無名関数は割り当てられる関数ハンドルのシグネチャを取るため、引数の型と戻り値の型を明示的に宣言する必要はありません。

無名関数が関数と同じスコープで宣言された変数にアクセスすることはまだできません（つまりクロージャとして使用することはできません）。

無名関数に対して複数の一致する使い方がある場合、曖昧さを解消できるよう、パラメータ型を明示的に指定する必要があります：

```cs
funcdef void A(int);
funcdef void B(float);
void func(A@) {}
void func(B@) {}

void main()
{
  // A が必要なことをコンパイラに伝えるために型を明示的に指定します
  func(function(int a) {});
}
```
