## Tutorial（チュートリアル）

**パス:** `/sdk/samples/tutorial/`

このサンプルは、AngelScript の基本、つまりエンジンの設定、スクリプトのロードとコンパイル、そして最終的にパラメータと戻り値を持つスクリプト関数の実行方法を説明することを目的として書かれています。

 - `asIScriptEngine::SetMessageCallback`
 - 時間切れになった時に実行を中断する `LineCallback()` 関数
 - 文字列 (Strings)
 - 登録されたグローバル関数
 - スクリプト関数のパラメータと戻り値
 - スクリプト例外に関する情報の取得
 - ライブラリがネイティブ呼び出し規約をサポートしていない場合のための `asIScriptGeneric`

## Concurrent scripts（並行スクリプト）

**パス:** `/sdk/samples/concurrent/`

このサンプルは、2つ以上の長時間実行スクリプトを [並行して](./doc_adv_concurrent) 実行する方法を示しています。スクリプトは `sleep()` 関数を呼び出すことで、自発的にキュー内の次のスクリプトに制御を渡します。

 - [doc_addon_ctxmgr](./doc_addon)
 - 複数のスクリプトの並行実行
 - `sleep()`
 - 文字列 (Strings)
 - 登録されたグローバル関数

## Console（コンソール）

**パス:** `/sdk/samples/console/`

このサンプルは、ユーザーがコマンドを入力したりアプリケーションを操作するための単純なスクリプト文を評価したりできる、シンプルなインタラクティブコンソールを実装しています。

ユーザーはコマンドラインから新しい変数や関数を定義することもできます。その後、これらの関数を実行して自動化タスクを実行することができます。

 - `ExecuteString`
 - `CompileFunction`、`CompileGlobalVar`、`RemoveFunction`、`RemoveGlobalVar`
 - グローバル関数と変数の列挙
 - 文字列 (Strings)
 - 登録されたグローバル関数とプロパティ
 - スクリプトステートメントからの結果の値を受け取り表示するためのオーバーロードを持つ特殊関数 `_grab()`

## Co-routines（コルーティン）

**パス:** `/sdk/samples/coroutine/`

このサンプルは、AngelScript で [コルーティン](./doc_adv_coroutine) を実装する方法を示しています。コルーティンはスクリプトから作成できるスレッドで、`yield()` を呼び出すことで自発的に互いに制御を渡し合います。

 - コンテキストマネージャー
 - 可変パラメータ構造を持ったスクリプトから作成されるコルーティン
 - 文字列 (Strings)
 - 登録されたグローバル関数
 - 可変引数型の処理
 - スクリプト関数への引数の受け渡し
 - ディクショナリ

## Events（イベント）

**パス:** `/sdk/samples/events/`

このサンプルでは、スクリプトエンジンが長時間実行中のスクリプトを実行します。スクリプトの実行はアプリケーションによって定期的に中断され、キーボードイベントを処理します。イベントは別の短いスクリプトを実行してからメインスクリプトの実行を再開します。イベント処理スクリプトは長時間実行中のスクリプトの状態を変更します。

 - 時間切れになった時に実行をサスペンドする `LineCallback()` 関数
 - 文字列 (Strings)
 - 登録されたグローバル関数
 - スクリプト化されたイベントハンドラー

## Include directive（インクルードディレクティブ）

**パス:** `/sdk/samples/include/`

このサンプルは、スクリプトライターが共通のスクリプトコードを再利用できるようにする `#include` ディレクティブのサポートを追加するための、非常にシンプルなプリプロセッサを実装する方法を示しています。プリプロセッサはインクルードされたスクリプトを複数のスクリプトセクションとして追加するだけで済みます。AngelScript がグローバル宣言を宣言順に関わらず解決できるためこれで問題ありません。プリプロセッサはスクリプトファイルが1回だけインクルードされることも確認するため、スクリプトライターは多重インクルードや複雑な循環インクルードを避けるために特別なことをする必要がありません。

 - スクリプトビルダー
 - 時間切れになった時に実行を中断する `LineCallback()` 関数
 - `#include` ディレクティブの処理
 - 循環した `#include` は自動的に解決されます

## Generic compiler（汎用コンパイラ）

**パス:** `/sdk/samples/asbuild/`

このサンプルは、スクリプトのオフラインコンパイルを提供するための汎用バイトコードコンパイラを構築する方法を示しています。アプリケーションインターフェースを定義する設定ファイルを入力として受け取り、ダミー関数とプロパティを使用してそれを登録し、その後スクリプトをコンパイルしてバイトコードをディスク上のファイルに保存します。

設定ファイルは、アプリケーションインターフェースが完全に登録された後に、バイトコードを実行するアプリケーションから `WriteConfigToFile` ヘルパー関数を呼び出すことで自動的に作成されることが望ましいです。

 - [事前コンパイル済みバイトコード](./doc_adv_precompile)
 - スクリプトビルダー
 - `asIScriptEngine::SetMessageCallback`
 - `asEP_INIT_GLOBAL_VARS_AFTER_BUILD`
 - `asIScriptEngine::ParseToken`
 - `asIScriptModule::SaveByteCode`
 - `asIBinaryStream`

## Command line runner（コマンドラインランナー）

**パス:** `/sdk/samples/asrun/`

このサンプルは AngelScript 用の非常に基本的なコマンドラインランナーを提供します。

また、ブレークポイントの設定、コードのステップ実行、変数の検査などをサポートした完全に機能するコマンドラインデバッガーも実装しています。

デバッガーの使用方法については、`asrun` のドキュメントを参照してください。

### asrun の使い方 (Usage)

```
asrun [-d] <script file> [<args>]
 -d             スクリプトをデバッグで実行するかどうかを指定します
 <script file>  実行するスクリプトファイル
 <args>         スクリプトへの0個以上の引数
```

これらの使用方法は引数なしでツールを実行した場合にも表示されます。

### スクリプト (Scripts)

スクリプトの実行のエントリポイントとして、asrun は `int main()` または `void main()` のいずれかの関数を探します。これらの関数のいずれも見つからない場合はエラーが報告されます。

スクリプトは、このマニュアルのスクリプト言語セクションに記載されているスクリプト言語と標準ライブラリのフルセットを使用することができます。

コマンドライン上で入力として指定されたスクリプトファイルは、インクルードディレクティブ `#include "<file name>"` で追加のファイルをインクルードすることができます。これにより、スクリプトファイルをより適切に整理し、一般的なロジックを複数スクリプト間で共有することができます。

### スクリプトのデバッグ方法 (How to debug scripts)

デバッガーでスクリプトを実行するには、コマンドライン引数 `-d` を追加するか、スクリプトに `#pragma debug` をインクルードしてください。これを行うと、デバッガーは次のようなプロンプトを表示します：

```
Debugging, waiting for commands. Type 'h' for help.
[dbg]>
```

これにより、ブレークポイントの設定、コードのステップ実行、変数の検査などが可能になります。利用可能なコマンドのリストを取得するには、プロンプトで `h` とタイプしてください。

## Game（ゲーム）

**パス:** `/sdk/samples/game/`

このサンプルは、スクリプティングライブラリをゲームエンジンに統合する方法の1つを示しています。プレイヤーがゾンビに食べられないようにするシンプルなゲームです。各ゲームオブジェクト型はその動作を制御する独自のスクリプトを持ち、それらは別々のモジュールに個別にロードされます。

 - `asIScriptModule`
 - `asITypeInfo::SetUserData`
 - グローバルインターフェース
 - スクリプトクラス
 - スクリプトビルダー
 - ハンドル
 - 共有スクリプトエンティティ
