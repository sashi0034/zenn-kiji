## Tutorial（チュートリアル）

**パス:** `/sdk/samples/tutorial/`

このサンプルは、AngelScript の基本的な使い方、すなわちエンジンの設定、スクリプトのロードとコンパイル、および引数や戻り値を持つスクリプト関数の実行方法を解説することを目的としています。

 - `asIScriptEngine::SetMessageCallback`
 - 時間切れになった時に実行を中断する `LineCallback()` 関数
 - 文字列 (Strings)
 - 登録されたグローバル関数
 - スクリプト関数のパラメータと戻り値
 - スクリプト例外に関する情報の取得
 - ライブラリがネイティブ呼び出し規約をサポートしていない場合のための `asIScriptGeneric`

## Concurrent scripts（並行スクリプト）

**パス:** `/sdk/samples/concurrent/`

このサンプルは、2つ以上の長時間実行されるスクリプトを[並行（Concurrent）](./doc_adv_concurrent)して実行する方法を示しています。各スクリプトは `sleep()` 関数を呼び出すことで、自発的に次のスクリプトへ実行権（制御）を譲ります。

 - [doc_addon_ctxmgr](./doc_addon)
 - 複数のスクリプトの並行実行
 - `sleep()`
 - 文字列 (Strings)
 - 登録されたグローバル関数

## Console（コンソール）

**パス:** `/sdk/samples/console/`

このサンプルでは、ユーザーがコマンドを入力したり、アプリケーションを操作するための簡単なスクリプト文を評価したりできる、対話型のシンプルなコンソールを実装しています。

ユーザーはコマンドラインから新しい変数や関数を定義することもできます。その後、これらの関数を実行して自動化タスクを実行することができます。

 - `ExecuteString`
 - `CompileFunction`、`CompileGlobalVar`、`RemoveFunction`、`RemoveGlobalVar`
 - グローバル関数と変数の列挙
 - 文字列 (Strings)
 - 登録されたグローバル関数とプロパティ
 - スクリプトステートメントからの結果の値を受け取り表示するためのオーバーロードを持つ特殊関数 `_grab()`

## Co-routines（コルーティン）

**パス:** `/sdk/samples/coroutine/`

このサンプルは、AngelScript で [コルーチン](./doc_adv_coroutine) を実装する方法を示しています。コルーチンはスクリプト内から作成可能な擬似的なスレッドであり、`yield()` を呼び出すことで明示的に実行権を互いに受け渡します。

 - コンテキストマネージャー
 - 可変パラメータ構造を持ったスクリプトから作成されるコルーティン
 - 文字列 (Strings)
 - 登録されたグローバル関数
 - 可変引数型の処理
 - スクリプト関数への引数の受け渡し
 - ディクショナリ

## Events（イベント）

**パス:** `/sdk/samples/events/`

このサンプルでは、メインの長時間実行スクリプトをホストアプリケーションが定期的に中断し、キーボードイベントなどを処理する方法を示しています。イベント発生時には別の短いスクリプトを実行し、その後メインスクリプトの実行を再開します。イベント処理用のスクリプトからメインスクリプトの状態を変更することも可能です。

 - 時間切れになった時に実行をサスペンドする `LineCallback()` 関数
 - 文字列 (Strings)
 - 登録されたグローバル関数
 - スクリプト化されたイベントハンドラー

## Include directive（インクルードディレクティブ）

**パス:** `/sdk/samples/include/`

このサンプルは、スクリプト開発者が共通のコードを再利用できるようにするための `#include` ディレクティブのサポートを追加する、シンプルなプリプロセッサの実装例です。このプリプロセッサは、インクルードされたファイルを単に別のスクリプトセクションとして追加します。AngelScript はグローバルな宣言をその記述順序に関係なく解決できるため、この単純な方式で問題なく動作します。また、同一ファイルが複数回読み込まれないように制御されているため、複雑な循環参照などを気にする必要もありません。

 - スクリプトビルダー
 - 時間切れになった時に実行を中断する `LineCallback()` 関数
 - `#include` ディレクティブの処理
 - 循環した `#include` は自動的に解決されます

## Generic compiler（汎用コンパイラ）

**パス:** `/sdk/samples/asbuild/`

このサンプルは、スクリプトのオフラインコンパイルを可能にする汎用バイトコードコンパイラの実装例です。アプリケーションインターフェースを定義する設定ファイルを入力として受け取り、ダミー関数やプロパティを使ってそれらを登録した上で、スクリプトをコンパイルしてバイトコードをディスクに保存します。

設定ファイルは、アプリケーション側のインターフェース登録が完了した後に、`WriteConfigToFile` ヘルパー関数を呼び出すことで自動生成するのが一般的です。

 - [事前コンパイル済みバイトコード](./doc_adv_precompile)
 - スクリプトビルダー
 - `asIScriptEngine::SetMessageCallback`
 - `asEP_INIT_GLOBAL_VARS_AFTER_BUILD`
 - `asIScriptEngine::ParseToken`
 - `asIScriptModule::SaveByteCode`
 - `asIBinaryStream`

## Command line runner（コマンドラインランナー）

**パス:** `/sdk/samples/asrun/`

このサンプルは AngelScript 用の非常に基本的なコマンドラインランナーを提供します。

また、ブレークポイントの設定、コードのステップ実行、変数の検査などをサポートした完全に機能するコマンドラインデバッガーも実装しています。

デバッガーの使用方法については、`asrun` のドキュメントを参照してください。

### asrun の使い方 (Usage)

```
asrun [-d] <script file> [<args>]
 -d             スクリプトをデバッグで実行するかどうかを指定します
 <script file>  実行するスクリプトファイル
 <args>         スクリプトへの0個以上の引数
```

これらの使用方法は引数なしでツールを実行した場合にも表示されます。

### スクリプト (Scripts)

スクリプトの実行のエントリポイントとして、asrun は `int main()` または `void main()` のいずれかの関数を探します。これらの関数のいずれも見つからない場合はエラーが報告されます。

スクリプトは、このマニュアルのスクリプト言語セクションに記載されているスクリプト言語と標準ライブラリのフルセットを使用することができます。

コマンドライン上で入力として指定されたスクリプトファイルは、インクルードディレクティブ `#include "<file name>"` で追加のファイルをインクルードすることができます。これにより、スクリプトファイルをより適切に整理し、一般的なロジックを複数スクリプト間で共有することができます。

### スクリプトのデバッグ方法 (How to debug scripts)

デバッガーでスクリプトを実行するには、コマンドライン引数 `-d` を追加するか、スクリプトに `#pragma debug` をインクルードしてください。これを行うと、デバッガーは次のようなプロンプトを表示します：

```
Debugging, waiting for commands. Type 'h' for help.
[dbg]>
```

これにより、ブレークポイントの設定、コードのステップ実行、変数の検査などが可能になります。利用可能なコマンドのリストを取得するには、プロンプトで `h` とタイプしてください。

## Game（ゲーム）

**パス:** `/sdk/samples/game/`

このサンプルは、スクリプトをゲームエンジンに統合する実践的な例です。プレイヤーがゾンビに捕まらないように逃げるシンプルなゲームで、各ゲームオブジェクト（プレイヤーや敵など）は独自の挙動を定義したスクリプトを持ち、それらは個別のモジュールとしてロードされます。

 - `asIScriptModule`
 - `asITypeInfo::SetUserData`
 - グローバルインターフェース
 - スクリプトクラス
 - スクリプトビルダー
 - ハンドル
 - 共有スクリプトエンティティ
