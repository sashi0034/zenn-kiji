:::message
ホストアプリケーションによって、独自のデータ型が追加されている場合があります。詳細については、各アプリケーションのマニュアルを参照してください。
:::

## プリミティブ型 (Primitives)

### void

`void` は実際にはデータ型ではなく、データ型の欠如のようなものです。関数がデータを返さないことをコンパイラに伝えるためにのみ使用できます。

### bool

`bool` は `true` または `false` の2つの値しか持たないブール型です。キーワード `true` と `false` は `bool` 型の定数であり、式の中でそのように使用することができます。

### 整数型 (Integer numbers)

| 型      | 最小値                     | 最大値                     |
|---------|--------------------------|--------------------------|
| `int8`  | -128                     | 127                      |
| `int16` | -32,768                  | 32,767                   |
| `int`   | -2,147,483,648           | 2,147,483,647            |
| `int64` | -9,223,372,036,854,775,808 | 9,223,372,036,854,775,807 |
| `uint8` | 0                        | 255                      |
| `uint16`| 0                        | 65,535                   |
| `uint`  | 0                        | 4,294,967,295            |
| `uint64`| 0                        | 18,446,744,073,709,551,615 |

スクリプトエンジンは 32 ビットデータ型に最適化されています。そのため、8 ビットや 16 ビットの型は、アプリケーションが提供する特定の変数にアクセスする場合にのみ使用することを推奨します。通常のローカル変数には 32 ビット型（`int` / `uint`）を使用するのが最適です。

`int32` は `int` のエイリアスで、`uint32` は `uint` のエイリアスです。

### 実数型 (Real numbers)

| 型       | 値の範囲                    | 最小の正の値         | 最大桁数 |
|----------|--------------------------|-------------------|--------|
| `float`  | +/- 3.402823466e+38      | 1.175494351e-38   | 6      |
| `double` | +/- 1.79769313486231e+308| 2.22507385850720e-308| 15   |

:::message
これらの数値範囲は、プラットフォームが IEEE 754 規格に従って浮動小数点数を表現していることを前提としています。
:::

最大精度を超える桁数を扱う場合、丸め誤差が発生する可能性があります。

**補足:** 実数は正と負の 0 または無限大、および NaN (Not-a-Number) という追加の値を持つこともあります。`float` の場合、NaN は32ビットのデータワード `0x7fc00000` で表されます。

## オブジェクトとハンドル (Objects and handles)

### オブジェクト (Objects)

オブジェクトには参照型と値型の2つの形式があります。

値型はプリミティブ型とよく似た動作をし、スタック上に割り当てられ、変数がスコープ外に出ると削除されます。これらの型はアプリケーションのみが登録できます。そのため、登録された型の詳細についてはアプリケーションのドキュメントを確認してください。

参照型はメモリヒープ上に割り当てられ、インスタンスへの別の参照が保持されている場合は、それを割り当てた最初の変数より長く生存する可能性があります。すべての [スクリプトで宣言されたクラス](./doc_script_class) は参照型です。[インターフェース](./doc_script_global#インターフェース-interfaces) は参照型の特殊な形式で、インスタンス化はできませんが、正確な型を知らずにインターフェースを実装するオブジェクトにアクセスするために使用できます。

```cs
obj o;      // オブジェクトがインスタンス化されます
o = obj();  // 一時的なインスタンスが作成され、
            // その値が変数に代入されます
```

### オブジェクトハンドル (Object handles)

オブジェクトハンドルは、他のオブジェクトへの参照を保持するために使用できる特殊な型です。オブジェクトハンドルである変数に対してメソッドを呼び出したりプロパティにアクセスしたりする時、エイリアスであるかのように、ハンドルが参照する実際のオブジェクトにアクセスします。ハンドルはオブジェクトのハンドルで初期化されていない限り、`null` であることに注意してください。

```cs
obj o;
obj@ a;           // a は null に初期化されます
obj@ b = @o;      // b は o への参照を保持します

b.ModifyMe();     // メソッドは元のオブジェクトを変更します

if( a is null )   // オブジェクトがオブジェクトを指しているかどうかを検証します
{
  @a = @b;        // a を b と同じオブジェクトへの参照にします
}
```

すべての型がハンドルをサポートしているわけではありません。プリミティブ型はハンドルを持てませんし、オブジェクト型の中にもハンドルの使用を禁止しているものがあります。どの型がハンドルを許可するかは、その型を登録したアプリケーションの設定に依存します。

オブジェクトハンドルと配列型の修飾子を組み合わせて、「配列へのハンドル」や「ハンドルの配列」などを定義することも可能です。

参照: [スクリプトのハンドル](./doc_script_handle)

## 関数ハンドル (Function handles)

関数ハンドルは、変数宣言が定義した関数シグネチャと一致するシグネチャを持つグローバル関数を動的に指すように設定できるデータ型です。関数ハンドルは一般的にコールバックに使用されます。つまり、何らかの条件に基づいてコードにコールバックできる必要があるが、コンパイル時には呼び出されるべきコードが分からない場合に使用されます。

関数ハンドルを使用するには、まずグローバルスコープまたはクラスのメンバーとして使用される [関数シグネチャを定義](./doc_script_global#funcdef-関数定義) する必要があります。それが完了したら、その定義を使用して変数を宣言することができます。

関数ハンドルの使用構文を示す例：

```cs
// 関数ハンドルの関数シグネチャを定義します
funcdef bool CALLBACK(int, int);

// これの使用方法を示す関数例
void main()
{
  // 関数ハンドルを宣言し、myCompare 関数を
  // 指すように設定します
  CALLBACK @func = @myCompare;

  // 関数ハンドルは 'is' 演算子で比較できます
  if( func is null )
  {
    print("The function handle is null\n");
    return;
  }

  // 通常の関数であるかのようにハンドルを通じて関数を呼び出します
  if( func(1, 2) )
  {
    print("The function returned true\n");
  }
  else
  {
    print("The function returned false\n");
  }
}

// この関数は同じ戻り値の型とパラメータ型を持っているため、
// CALLBACK の定義と一致します
bool myCompare(int a, int b)
{
  return a > b;
}
```

### デリゲート (Delegates)

クラスのメソッドへの関数ハンドルを取ることも可能ですが、この場合クラスのメソッドは呼び出しに使用されるオブジェクトインスタンスにバインドされなければなりません。このバインドを行うことをデリゲートの作成と呼び、クラスのメソッドを引数として渡した宣言された関数定義に対して構築呼び出しを実行することで行われます。

```cs
class A
{
  bool Cmp(int a, int b)
  {
     count++;
     return a > b;
  }
  int count = 0;
}

void main()
{
  A a;

  // A::Cmp クラスメソッドのデリゲートを作成します
  CALLBACK @func = CALLBACK(a.Cmp);

  // グローバル関数であるかのようにデリゲートを通常通り呼び出します
  if( func(1,2) )
  {
    print("The function returned true\n");
  }
  else
  {
    print("The function returned false\n");
  }

  printf("The number of comparisons performed is "+a.count+"\n");
}
```

## 文字列 (Strings)

:::message
文字列はアプリケーションが [そのサポートを登録](./doc_addon#string-オブジェクト) した場合にのみスクリプトで使用可能です。文字列の使用構文は使用しているアプリケーションによって異なる場合がありますので、詳細についてはアプリケーションのマニュアルを参照してください。
:::

文字列はアプリケーションの設定に応じて、バイトまたは16ビットワードの配列を保持します。通常はテキストを格納するために使用されますが、実際にはあらゆる種類のバイナリデータを格納することができます。

AngelScript 言語は通常の引用符付き文字列とドキュメント文字列（ヒアドック文字列と呼ばれる）の2種類の文字列定数をサポートしています。

通常の文字列はダブルクォーテーションマーク (`"`) またはシングルクォーテーションマーク (`'`) の間に書かれます。定数文字列内では、通常のエディタでは書けない可能性のある正確なバイト値を書くために、いくつかのエスケープシーケンスが使用できます。

| シーケンス   | 値        | 説明                         |
|------------|----------|------------------------------|
| `\0`       | 0        | ヌル文字                       |
| `\\`       | 92       | バックスラッシュ                  |
| `\'`       | 39       | シングルクォーテーションマーク        |
| `\"`       | 34       | ダブルクォーテーションマーク          |
| `\n`       | 10       | 改行                           |
| `\r`       | 13       | キャリッジリターン                 |
| `\t`       | 9        | タブ文字                       |
| `\xFFFF`   | 0xFFFF   | FFFF は必要な値を表す1〜4桁の16進数で置き換えてください。アプリケーションが8ビット文字列を使用する場合は255までの値のみ受け入れられます。 |
| `\uFFFF`   | 0xFFFF   | FFFF は Unicode コードポイントを表す16進数で置き換えてください。 |
| `\UFFFFFFFF`| 0xFFFFFFFF| FFFFFFFF は Unicode コードポイントを表す16進数で置き換えてください。 |

```cs
string str1 = "This is a string with \"escape sequences\".";
string str2 = 'If single quotes are used then double quotes can be included without "escape sequences".';
```

ヒアドック文字列はエスケープシーケンスを処理せずに大量のテキストを含めるために設計されています。ヒアドック文字列はトリプルダブルクォーテーションマーク (`"""`) で囲まれており、複数行にまたがることができます。文字列の開始から最初の改行までの文字が空白のみの場合、コンパイラによって自動的に削除されます。同様に、最後の改行から文字列の終わりまでの文字が空白のみの場合も削除されます。

```cs
string str = """
This is some text without "escape sequences". This is some text.
This is some text. This is some text. This is some text. This is
some text. This is some text. This is some text. This is some
text. This is some text. This is some text. This is some text.
This is some text.
""";
```

2つ以上の文字列定数が、空白やコメントのみを挟んで並んでいる場合、コンパイラはそれらを1つの連続した文字列として連結します。

```cs
string str = "First line.\n"
             "Second line.\n"
             "Third line.\n";
```

エスケープシーケンス `\u` と `\U` は、アプリケーションの設定に応じて指定された Unicode コードポイントを UTF-8 または UTF-16 エンコードのシーケンスとして追加します。有効な Unicode 5.1 のコードポイントのみが受け入れられます。つまり、U+D800 から U+DFFF（サロゲートペア用に予約）または U+10FFFF を超えるコードポイントは受け入れられません。

参照: [文字列の標準ライブラリ](./doc_script_stdlib)

## 自動型宣言 (Auto declarations)

代入スタイルの変数宣言のデータ型として `auto` を使用することができます。

変数に適切な型が自動的に決定されます。

```cs
auto i = 18;         // i は整数になります
auto f = 18 + 5.f;   // f の型は float に解決されます
auto o = getLongObjectTypeNameById(id); // 長い型名の冗長性を避けられます
```

`auto` に `const` を付けて定数値を強制することもできます：

```cs
const auto i = 2;  // i は 'const int' として型付けされます
```

ハンドルをサポートする型の場合、`auto` は値代入よりも効率的なためハンドルとして解決されます。何らかの理由で変数がハンドルであってはならない場合は、`auto` キーワードを使用しないでください。

```cs
auto  a = getObject();  // auto は 'obj@' として型付けされます
auto@ b = getObject();  // より明示的にしたい場合は @auto も使用できます
```

オートハンドルはクラスメンバーの宣言には使用できません。解決がコンストラクタに依存するためです。
