---
title: "共有スクリプトエンティティ (Shared script entities)"
---

アプリケーションが複数のスクリプトモジュールを使用してアプリケーションの異なる部分を制御する場合、スクリプトの一部をスクリプトモジュール間で共有できるようにすることが有益な場合があります。共有エンティティの主な利点はメモリ消費の削減と、共有エンティティの型がモジュール間で同じであり、これが使用されるモジュール間の情報交換が簡素化されることです。

共有エンティティには制限があり、非共有エンティティにアクセスできません。非共有エンティティはコンパイルされたスクリプトモジュールにのみ固有であるためです。

## 共有エンティティの宣言方法 (How to declare shared entities)

共有エンティティを宣言するには、通常の宣言の前に `shared` キーワードを付けるだけです：

```cs
shared class Foo
{
  void MethodInFoo(int b) { bar = b; }
  int bar;
}

shared void GlobalFunc() {}
```

スクリプトが共有エンティティ内から非共有エンティティにアクセスしようとすると、コンパイラはエラーメッセージを報告します。

当然、機能するために、エンティティを共有するすべてのモジュールのスクリプトはエンティティを同じ方法で実装しなければなりません。そうでない場合、コンパイラは最初に共有エンティティを実装したスクリプトの後にコンパイルされるスクリプトでエラーを報告します。

実装が同じであることを保証する最も簡単な方法は同じソースファイルを使用することですが、これは必須ではありません。

## 外部共有エンティティ (External shared entities)

各モジュールで完全な共有エンティティを宣言する代わりに、以前にコンパイルされたと分かっている共有エンティティを外部として宣言することができます。これによりスクリプトを短縮でき、ソースコードのサイズとコンパイル時間の両方を削減できます。

共有エンティティを外部として宣言するには、宣言の前に `external` キーワードを追加し、エンティティを一意に識別するシグネチャの後にステートメントを `;` で終了します：

```cs
external shared class Foo;
external shared void GlobalFunc();
```

外部として宣言された共有エンティティをコンパイルする際に、他のモジュールでまだその共有エンティティがコンパイルされていない場合、コンパイラはエラーメッセージを報告します。

## 共有できるもの (What can be shared)

現在は [クラス](./doc_script_class)、[インターフェース](./doc_script_global#インターフェース-interfaces)、[関数](./doc_script_function)、[列挙型](./doc_script_global#列挙型-enums)、および [funcdefs](./doc_script_global#funcdef-関数定義) エンティティのみが共有できます。

将来のバージョンでは [グローバル変数](./doc_script_global#グローバル変数-variables) も共有できるようになる可能性があります。
